# 🧟‍♂️ Vir_prank – Windows Update Simulator

Шуточный симулятор «обновления Windows», который имитирует процесс установки обновлений с забавными эффектами.  
Программа создаёт иллюзию серьёзного системного процесса: блокирует закрытие окна, включает полноэкранное мерцание, показывает прогресс‑бар и выдаёт «системные» сообщения об ошибках.

---

## ⚠️ Важное примечание

**Этот проект является шуточным симулятором и не является настоящим вирусом.**  
Код создан исключительно в развлекательных целях и не предназначен для нанесения вреда.

---

## 🎯 О проекте

Проект демонстрирует базовые принципы работы с графическим интерфейсом (Tkinter), многопоточностью и таймерами в Python.  
Весёлая пародия на «синий экран» и панические сообщения Windows.

---

## 🎮 Особенности

- **Имитация системных процессов** – визуально похожа на установку обновлений.
- **Блокировка закрытия окна** – на 2 минуты окно нельзя закрыть стандартными средствами.
- **Визуальные эффекты** – полноэкранное мерцание и смена цветов.
- **Реалистичные сообщения** – «Ошибка 0x80070005», «Не удалось установить обновление» и т.п.
- **Прогресс‑бар** – медленно заполняется, создавая ощущение долгой установки.

## 📋 Установка и запуск

1. Убедись, что у тебя установлен Python 3.
2. Скачай файл `joke_virus.py`.
3. Запусти в терминале:

```bash
python joke_virus.py
```

Или просто дважды кликни по файлу (на Windows).

---

## 🎯 Как использовать

1. Запусти скрипт.
2. Наблюдай за «процессом обновления».
3. Наслаждайся эффектом!
4. Через 2 минуты окно закроется автоматически (или ты можешь принудительно завершить процесс, если надоест).
